# ROKO 4 EVER - User Roles

## Player
- Register Account
- Join Tournament
- Pay Entry Fee
- View Results
- Withdraw Prize

## Moderator
- Verify Results
- Monitor Matches
- Report Violations

## Admin
- Create Tournament
- Edit Tournament
- Publish Results
- Manage Wallet
- Manage Users

## Super Admin
- Full System Access
- Fraud Monitoring
- Security Control
- Revenue Monitoring
